# HabitFlow Dashboard

A responsive React + Tailwind habit tracker dashboard.

**Live demo:** [habit-flow-mocha-three.vercel.app](https://habit-flow-mocha-three.vercel.app)

## Features

- Add a new habit
- Mark a habit as complete or incomplete
- Delete a habit
- Live completion and progress statistics
- Responsive sidebar and mobile layout

## Known limitation

Data is currently stored in local React state only — habits reset on page refresh. Persistent storage (localStorage or a backend) is planned as a next step.

## Tech Stack

- React
- Tailwind CSS
- Vite

## Run it locally

1. Install [Node.js](https://nodejs.org/) (version 18 or newer).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local link shown in the terminal (usually `http://localhost:5173`).
